2025 年 4 月：无聊至极

至此我们还是回归比较轻松愉快的话题。

作为背景，我最近阅读了许多风味各异的轻小说。轻小说除了通常接触的文库本，还有 web 小说，在各种网站上连载。当然有许多人对 web 小说有着又臭又长的刻板印象，以我个人经验，此言基本属实 —— 字数太多不一定是内容丰富，也有可能是在水更新；更何况挖坑不填的现象也屡见不鲜。不过 web 亦有两个独特的优势：

一是纸本受制于出版制度和商业要求，作品不会很多，更何况轻小说的腰斩在近年来随着作品的增加也愈发扩大化。因此，有许多作者是 web 文库化或是文库转 web 的，无论什么情况腰斩之后仍然在 web 更新。

二是 web 能探索纸本难以出版或不受欢迎的题材。虽然客观而言，“可被纸媒接受的题材”的边界正在变得越发模糊，但毫无疑问 web 仍然有其存在意义。比如说背德系，在 web 中不能说是比比皆是 —— 虽然由于我对此不甚感冒，恕我不能评价质量。

不过，以上仍然只是个背景。我为何执着于强调故事的背景呢？因为这符合我探索世界的逻辑 —— 正是因为事物存在互相关联，才使我凭借好奇心能找到这处互联网深海中的礁石。

那么，事情是这样 —— 我在 web 的头部平台之一 Kakuyomu 上发现了非小说的分类（散文·纪实、创作论·评论），并深陷其中无法自拔。

哎，这么一写下来就很富有戏剧性了。事实上，阅读这些无甚营养的非小说作品，反而比绝大多数的轻小说都更能予以我乐趣和启发。

譬如说这一篇：年轻人远离轻小说　约10年市场减半的冲击（机翻站）@らんた，是我在收集与轻小说相关的统计数据时发现的。概而言之，轻小说市场的萎缩是因为年轻人远离轻小说，分别流向了儿童文学、轻文艺等其他类型，而仅剩的轻小说的顶梁柱们大多是动画、漫画等知名 IP 小说化的作品。而由于轻小说作家的文笔弗如轻文艺和大众作家，“轻小说市场”实际已经死了。

而且，因为都是「第三卷就突然腰斩的轻小说」，所以才会失去读者的信赖，读者才会逃向儿童文学、轻文艺吧？
差不多该停止这种乱发商法了吧？不觉得对读者很失礼吗？而且，这种腰斩轻小说，就算改编成漫画，也会连漫画一起腰斩，结果变成「轻小说改编的漫画都是地雷」的评价，形成恶性循环。我认为就是因为出版社如此背叛读者的信赖，读者才会逃向值得信赖的儿童文学、轻文艺。
确实，我也能理解《周刊文春》「轻小说的质量并没有下降。销量下降的原因，是因为锁定读者群错误」的主张。但真的只有这样吗？我认为「都是腰斩」的轻小说现状，才是初高中生远离轻小说的真正原因。也就是说，让初高中生读者伤心，远离轻小说的另一个原因，不就是「轻小说的新刊都是腰斩」吗？
听好了，大人会说「这就是资本主义，没办法」，然后冷淡地看完腰斩的轻小说，接着寻找下一部作品。然后……大人轻小说读者层会因为工作或结婚，自然地从轻小说毕业。但是初高中生不同。腰斩这种行为，会伤害到真正的轻小说粉丝。因为，他们牺牲了宝贵的学习时间或社团活动时间，却受到这种对待，会觉得自己「被背叛」了。毕竟他们正值多愁善感的年纪。
失去的信赖，可不是那么容易就能取回的哦？

当然我不想论述这种论调的正确性；我所言的趣味性即是，如同在我七八岁的时候翻开爸爸带来的《商业周刊》，因为当时的我看不懂复杂的文字，第一时间就去看图表并深感震撼。靠统计数据说话果然是一件天生有趣的事情。

而らんた还写了不止一篇，在有趣之外还提供了不少豆知识：

如何分辨真正的编辑（机翻站）提到了轻小说的腰斩线一般是首周 2500 本，相当于首月 5000 本。这个数字对理解 O 榜水下的情况很有帮助。

然后呢，写这种东西就会有人问「你是编辑吗？」
不是。我只是在《社会常识》中写「编辑这种职业是这样的人」而已。

网络征稿要以参加祭典的心态参加（机翻站）则是更加直截了当地劝退了试图以 web 公募出道的新人们，顺便纠正了一下关于儿童文学的刻板印象：

即使如此，还是想在接近轻小说的领域投稿的人。要不要投稿儿童文学的新人奖？绝对不要投稿网络小说。然后，用稿纸或打印纸寄出。如何？觉悟完全不同吧？能感受到责任感吧？这才是真正的「公募」。
为什么轻小说以外的文艺领域都是用邮寄方式投稿呢 —— 仔细想想吧。在这个IT时代，刻意选择邮寄方式的理由，稍微思考一下比较好。是为了防止恶作剧投稿吧？这点小事应该明白吧？还有，也包含着「好好想想，你真的有资格投稿吗？」的意思。
儿童文学是接近轻小说的世界。无论如何都想「在接近轻小说的世界写作」的话，就去儿童文学的领域吧。如果能在那边生存下来，你就是真正的作家。遗憾的是，轻小说作家只是消耗品。所以再强调一次，绝对不要因为轻小说的网络公开招募落选就放弃写作。因为那是「兴趣」吧？
网络公开招募是「祭典」。认真度不同。你没有认真，自尊心却很高。如果真的有落选就封笔的觉悟，就不要待在这种地方，赶快用「稿纸」寄去儿童文学的公开招募。办得到吗？

上了高中后请务必读读看　你的出路（机翻站）讲述了日本的高中竞争是多么激烈……大概吧。总而言之比较搞笑的是介绍了日本法律可以卡你的 bug —— 没错，不是你卡法律而是你被法律卡了。当然这个对日本人来说可能并不好笑。

2024年道路交通法修正案通过后，即使是没有驾照的人，骑自行车被开罚单也会被处以一年以下徒刑或三十万日圆以下罚金。可能还会被要求参加「自行车驾驶者讲习」。也就是说，什么都没做的善良市民会被加上「前科」。这可不是不能参加大学推荐入学考试的问题。就算上了大学，可能也没有「工作」。

「创作论·评论」这个分类下主要还是创作论，而想来我们的读者大概对怎么写小说毫无关心。那不如来看看「散文·纪实」：除了相当一部分可能有意思但我没时间看的非虚构人生故事以外，还有散文 —— 而这是最有趣的部分。

走在山路上的同时……🌳🌼🌼🌳（机翻站） —— 字面意思，是野生植物图鉴。

我的创作经历（机翻站）—— 一篇过于漫长的自传。此等详细又横跨了几十年的时间，当作社会侧面的纪实来读也未尝不可。不过作者好像写到就「超级机器人大战」上头了，现在已经写了 20 多话了。

Kakuyomu 小说的真相~从215,590部作品的数据中挖掘本性（机翻站）—— 照例会有的数据统计文。实际上关于如何获取轻小说的数据，我最近做了一点小工具，但是大概率也用不上。

照例会有的读写报告：

  • Kakuyomu 反乌托邦杂志（机翻站）
  • 擅长阅读的我挑战写作的奋斗记（机翻站）
  • カクヨム初心者さまにむけて　ウチのクセモノ！（机翻站）—— 短小但趣味性很高。

还有许多读写报告我可能感兴趣但没能仔细阅读，因为它们的连载时间太长了，排行榜上横跨十年的都比比皆是。

照例会有的业界真实：

  • ◆第6回网络小说大赏得奖，书籍化作家（？）的随笔◆（机翻站）—— 《黑暗骑士物语》的作者。在这篇文章中我们了解到，2018年6月文库出版，10月就通知腰斩，这个速度还是……相当快的。还可以了解到一点网络小说平台的变迁。另外，后来 4 年，作者在 Kakuyomu 上收入 136 万日元，事实性地证明了书籍化的收入还真可能不如网络收益化。

以及并非会有的杉井光：

  • 没有比小说家赚钱更轻松愉快的生意了（机翻站） —— 你猜为啥偏偏这篇有人翻译了。

关于纪实文学，那可太多了！有抗癌抗疫的，有陆上自卫队的，有当书店店员推销轻小说的，有打官司获胜的，有上约等于异世界的底边工业高中的，有性虐待、NTR 和 LGBT 史的。光怪陆离。虽不能考证其真实性，亦不见得此等故事有多么稀有，但我觉得这就是纪实文学的魅力所在 —— 存在本身即是故事。

当然还有做饭的。描写食物确实能激发人的味蕾。

不过还是推一篇比较二次元的：单色苏打 (Monochrome Cider)（机翻站）—— 关于 1999 年夏天，关于上世纪电玩的怀旧故事。

迎接高中最后夏天的男学生，与在学校屋顶遇见的游戏少女结婚，1999年的青春故事。

但还有更重量级的，也正是我能够如此沉迷其中的文章：

平日黒髪お姉さん 的

  • 也有写不出来的夜晚（机翻站）
  • 语言不足的自言自语（机翻站）
  • 讨厌努力的慢笔作家想尽快写出小说的方法～读了创作书籍却完全无法理解的厌倦性人类的小说攻略～（机翻站）

※創作ってことにしててください(´；ω；`)
请把它当作创作吧(´；ω；`)

简而言之，太过轻松有趣了！

譬如说语言不足 [127] 关于能开心阅读书的，只有自己喜欢的类型这件事：（以下片断均有节略）

那种把文章玩弄得很厉害的文体，我实在读不下去。久违地遇到无法读到最后的小说，我就放弃了。
那部小说的书名是——这个。
《伪装成知识分子的推理少女与下流老师》
被评为HJ文库最大问题作品的作品。
与其说完全不懂它好在哪里，应该说，我读完开头的两成时……
「啊，不行了。我看不下去……」
就这样放弃阅读了(´；ω；`)
因为文体太有个性，读起来很累。对我来说，只是拙劣的文章。
感觉就像西尾维新先生的文章之啰嗦，混合了舞城王太郎先生或入间人间先生的气势。
文章像是只从上述的人们身上抽出缺点熬煮而成，我觉得不能拿给别人看。

首先我没有不尊重青……老师的意思。

[165] 不能以常见的题材为主轴吧：

我打算写一部以轻小说常见桥段为题材的作品。
但内容空泛又无聊。
简单说明的话——
就是文艺社的学长学妹不断聊着轻小说常见桥段的作品。
举例来说——
「虽然异世界转生很流行，但世上的人都想转生吗？」
「后宫恋爱喜剧在建立后宫前就会变成修罗场，这才是现实吧？」
「轻小说里的女主角虽然被称为无脑女角，但现实的女生……也会轻易跟在帅哥后面走吧。」
「被诱惑系女角引诱的话，只要是男人都会忍不住出手吧。」
就像这样——
文艺社的学长与学妹，针对轻小说的疑问，一话讨论一个疑问，互相议论并找出答案的故事。
刚开始写时虽然很有趣——
但中途就变得很无聊（笑）。
原因是——
变成只是在批判与说坏话。
我痛切感受到，若知识不够，就无法只凭浅薄的知识述说meta笑点，写出娱乐作品。
必须由造诣很深的人来写——
内容会变成只是批评自己不喜欢的剧情，不是人人都适合看。
说到底——
因为是以其他作品为基础写成的作品，不知道那些作品的人就无法享受乐趣。此外，因为是以贬低其他作品为前提写成的作品，所以不会让人觉得有趣。
如果要写——
会变成两～三万字的短篇小说吧。
再写下去一定会变得无聊。

因此，传奇轻小说家望公太的《小鸟游酱过于喜爱腰斩漫画》这本确实是神作！当然，不能有续集，也不会有（大概）。顺便一提，我在阅读时感到这本书很短，实际也的确如此，文库本不到300页，译本也只有 7.1 万字，在文库本中算是较短的。

再顺便一提，这种每行大概不超过 30 个字的分段法是十分适合手机阅读的，所以确实是锻炼过的力求读者轻松的写法。

※最后补一句，这个设定最好是学长和学妹。如果立场倒转的话就无法利用叙述性诡计了。

[211] 从淀粉酶问题思考的阅读理解讲座：

请阅读下一段文字。
一种名为淀粉酶的酵素，能够分解由葡萄糖连接而成的淀粉。但即使同样是葡萄糖所构成，淀粉酶也无法分解形状不同的纤维素。
请从选项中选出一个最适切的字词，填补以下这段文字中的空格。
纤维素的形状与（　　）不同。
（1）淀粉 （2）淀粉酶
（3）葡萄糖 （4）酵素

[272] 对家庭餐厅的店员一见钟情。鼓起勇气把写着联络方式的纸条递给她后，收到了回复。之后每天反复交流的结果……居然是这种结局！！：

自己看吧。

[302] 成为彩心真优原型的女孩子：

彩心真优的原型是真实存在的。她是我高中时代的同学。虽然我们从未同班过，但我一直都在远处关注着她的活跃。
然后——
其实前几天——高中毕业之后，已经……还是别数了。因为就算数了也只会感到悲伤。
我偶然遇到了彩心真优的原型。这或许也是一种缘分。
就算被说恶心也没关系。
为了自己的信念而行动吧——！！
我这么想着，跑向了她。
「如果是我认错人了，那我先道歉。请问——你是○○同学吗？」
然后，对方瞪大了眼睛。这也难怪……
因为那已经是很久以前的事了。
不过，让我再说一句。
那孩子现在也美得不得了。
在雨中，她今天也撑着伞站在那里。她似乎在等人，单手拿着手机，东张西望地确认着周围。
米色的针织衫衬托出她纤细的身体，从长裙的开衩处露出的白皙肌肤，让人心跳加速。
学生时代还残留着一些孩子气，现在则给人一种美丽成熟女性的感觉。
是我所追求的成熟大姐姐。

那很变态了（笑）。

写不出来 [24] 【2014～2023】自己的文体改变太大笑死：

2018年3月
我的学妹最棒了。应该说她曾经最棒。照理来说，她的方向性应该和我完全相反，但不知为何，我们之间却有着如同磁铁的两极互相吸引般，命运般的邂逅。即使没有，我们还是相遇了。
因为学妹虽然有着成熟的身体，却很愿意裸露。她就像冬眠的生物到了夏天会为了适应环境，正确来说，就像变色龙为了隐藏自己、保护自己不受外敌侵扰而脱掉衣服一样。
她是专职的裸体族。一到夏天，她就会开始在社办里走来走去，完全不在意被人看见……。在只有我和她存在的这间社办里。

从这篇文章中可以看到他十年间的文笔反复跳跃……以及变态程度的愈演愈烈。

还有很多很多写作点子和生活故事。其有趣之处在于 —— 轻小说里根本看不到嘛。

当然限于篇幅，以上只展示了我印象深刻的几篇。实际上还有浩如烟海的趣味片断，就请各位读者自行鉴赏吧。

总而言之，整天读轻小说肯定不是个事。说不定看看窗外就突然发现新世界了呢？
